# Согласованный вариант сайта — 5 сентября 2026

Пользователь согласовал перенос варианта v4 в GitHub и публикацию на GitHub Pages. Этот документ заменяет более ранние указания о неподтверждённом эскизе в SITE_BUILD_LOG.md.

## Финальное решение

- Кнопка «Написать Любе» имеет форму эллипса 164 × 100 px. Орбиты повторяют её пропорции; вокруг движутся три планеты. Ссылка на личный Telegram сохранена.
- Справа на первом экране размещена инфографика с заголовком «От вопроса к готовому решению». Внутри кругов — «Запрос», «Встреча», «Выбор», без цифр. Под ними — «Что волнует», «Смотрим глубже», «Ваш следующий шаг».
- Второй круг ниже первого, третий выше первого. Линии соединяют границы кругов и пересчитываются при изменении размеров.
- Старый большой раздел «Как это происходит» скрывается после успешного добавления новой схемы. Его исходный JSX пока сохранён как резерв.
- На узких экранах инфографика размещается в потоке, чтобы не перекрывать текст или кнопку.
- В карточке обучения остаётся «Мастер Кундалини Рейки — 23 000 ₽»; публичное предложение месячного сопровождения исключено.
- Под Прашна-видео — ссылка «Группа Любы во ВКонтакте» на https://vk.ru/astrospez. Отдельная обложка этого ролика убрана.

## Шрифты

Используются уже подключённые в index.html семейства: Manrope 400 для кнопки, подписей и кругов; Playfair Display 500 для заголовка инфографики. Ссылка на Google Fonts и существующие стили остальных разделов не изменены. Georgia/system-ui остаются только резервными шрифтами. В автономном эскизе использовались резервные шрифты; он не заменяет сайт.

## Публикация и проверка

Публикуются исходные файлы сайта из корня репозитория, а не HTML-эскиз со скриншотом. Оригинальные фотографии, видео, звук и прочие разделы сохранены. Папка dist содержит историческую сборку и не должна использоваться для нового размещения без полной пересборки через npm run build.

Локальное превью v4 проверено визуально на 1440 и 390 px; код прошёл проверку синтаксиса. Проверка загрузки реальных веб-шрифтов и обновлённой страницы на внешнем GitHub Pages из среды ассистента пока недоступна из-за сетевого ограничения. После слияния необходимо проверить результат публикации и при необходимости обновить страницу без кеша.

Бот и настройки платежей в рамках этих изменений не затрагиваются.
